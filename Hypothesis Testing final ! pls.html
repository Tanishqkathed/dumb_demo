Tail Direction

One-Tailed vs Two-Tailed Test

➡️

One-Tailed

H₁ specifies direction: μ > μ₀ or μ < μ₀. All α is placed in one tail, so the rejection region is on one side , either on left or right.

DirectionalCritical Z at α=0.05 → 1.645
↔️

Two-Tailed

H₀ says μ = μ₀ and H₁ says μ ≠ μ₀. The significance level is split equally between both tails, so extreme values on either side can reject H₀.

Non-directionalCritical Z at α=0.05 → ±1.96

Error Logic

Type I & Type II Errors

Type I Error (α)

Reject H₀ when it's TRUE. False positive. Probability = α.

Type II Error (β)

Fail to reject H₀ when it's FALSE. False negative. Probability = β.

Test Selection

Z-Test vs T-Test

📐

Z-Test

Large sample size, usually n >= 25 and population variance σ is known. Uses the standard normal distribution.

z = (x̄ − μ₀) / (σ / √n)
Known σ
📏

T-Test

Small sample size, usually n < 25 and population variance is σ unknown. Uses the t-distribution.

t = (x̄ − μ₀) / (s / √n)
Unknown σ

Sample Structures

One-Sample & Two-Sample Tests

🎯

One-Sample

When we have only one group and we compare its mean (sample mean) with a known value, usually the population mean.

⚖️

Independent Two-Sample

Compare means of two unrelated or different groups.

Example: One-sample asks whether average score ≠ 75, while a two-sample test can compare Method A vs Method B.
